## Round 9b (QUEUED — build only after round 9a is approved) — Owner Game Editor inside the game
The owner wants to adjust the real match screen directly. Add an **Editor mode** to the game, opened with the URL parameter `?editor=1` (and a hidden owner shortcut, Ctrl+Shift+E). It is never shown to normal players. The match keeps running underneath (the owner can play cards, move creatures and see effects while editing); a **Freeze** toggle pauses the AI and timers.

- **Everything gets grab handles:** every HUD piece (hand area, both deck piles, crystal counters and Flow/bank badges, both Commander hearts, phase/turn text, Menu, Done, Recenter, pop-out menu, banners/pop-ups, card pop-out size), the board mapping (4 corners), and each 3D piece type. Drag to move, corner handles to resize (proportional by default, Shift for free; no stretching of images unless the owner explicitly turns on "allow stretch"). A **Hide handles** toggle (H) shows the clean screen. Snap guides to screen edges/centers, arrow keys nudge 1 px (Shift = 10 px).
- **Side panel with drop-down sections** (collapsible, one open at a time per level): Layout, Text, Characters, Effects, Arena, Frames & Menus, Music & Sound, Save.
- **Text:** select any on-screen text to edit its words (where it isn't game data), font size, weight, color (palette picker plus custom), outline/glow strength, alignment, and position. Card text stays data-driven but its size/scale can be adjusted per card zone.
- **Characters:** a global "all creatures" size slider, per-faction size, and per-card-type override (pick a card from a list → its own size, height offset, facing); **Commander** size, position on its square/fortress, and facing; mine size; stat-badge size. Changes apply live to pieces on the board.
- **Effects:** every effect has adjustment sliders in its own drop-down: the arena effects (flames, glows, lanterns, waterfalls, acid pools, banners, plants, water shimmer, fireflies; each instance and "all of this type": brightness, size, speed, color, on/off — the owner says the flames are too bright), card glow/halo (thickness, brightness, color per faction), playable-card halo, flow particles, hit/spell effects (scale, brightness, duration), bloom/overall brightness.
- **Frames & Menus (new):** the owner can **drop in a graphic overlay** (PNG/JPG/WebP, drag-and-drop or file picker) as a frame/border or panel, place and size it (with 9-slice option so borders don't stretch), set its layer (behind/in front of HUD), and **put menus and HUD pieces inside it** (snap a HUD element or menu list into a frame; it then moves with the frame). Frames can also be added to menus (main menu, deck builder, Choose Your Commander) the same way. Uploaded images are stored in the layout (embedded or saved to `public/owner-art/`).
- **Arena:** same controls as the owner's Arena Editor for the painted arena (look, effects, cut-outs, board corners), so later fixes don't need the separate page.
- **Save:** everything the editor changes is stored in one file, **`public/owner-layout.json`** (versioned; the game loads it at start; missing values fall back to today's defaults). Buttons: Save to browser (instant preview), **Export layout** (downloads the JSON), **Import layout** (load a JSON file, including one exported from the owner's Claude Game Editor page, same format), Reset section, Undo/Redo (at least 30 steps). The owner sends the exported file; it gets committed as the new default.
- Document the JSON format in `docs/owner-layout.md` (keys, units: screen positions as % of the 16:9 frame, sizes as % of frame height, effects as multipliers, colors as hex).


Import/export use exactly the owner's Game Editor layout format (`factory-design/owner-layouts/final-draft/layout.json`, reference page `factory-design/owner-tools/game-editor-source.html`), including faction themes, banks, Crystal Flow, hand and menu settings from round 9a.

**Tests:** editor opens only with `?editor=1`/shortcut; handles appear/hide; moving and resizing a HUD piece changes its position/size and persists after reload; a text edit persists; global and per-type creature size apply; effect brightness slider changes the effect; dropping an image creates a frame; a HUD piece placed into a frame moves with it; export→import round-trips identical JSON; importing the owner's final-draft layout reproduces the 9a screen; the game without the editor renders exactly as before. Report screenshots of the editor open with handles at 1920 × 1080.
