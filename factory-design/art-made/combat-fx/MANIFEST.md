# Combat FX stickers (Brush, 2026-10-30)
Painted, transparent, 512x512 (PNG + WebP). Made in Ken's ChatGPT, matched to the game's existing pop/bonk, boom, ka-boom. Existing game files public/art/pop/{bonk,boom,ka-boom}.webp are only ~180px; these are bigger replacements/additions.
Hit words: wham, bonk, clang, smack, ka-boom, thwack, pow, klunk, splat
Dizzy stars: dizzy-stars-1, dizzy-stars-2, dizzy-stars-3
Impact puffs: puff-big, puff-ring, puff-streak
Sparkle flashes: sparkle-4, sparkle-8, sparkle-ring
Source sheets (green screen): ref/br-fxsheet-1.png, br-fxsheet-2.png; cut script ref/cut.py
