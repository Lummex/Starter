# Oreheart — Phase 1a build notes (Revision 2)

Vite + TypeScript (vanilla DOM) + Three.js. `npm run build` → `dist/`; `npm test` → Vitest (engine + AI, 43 tests).

## What was built
- **Rules engine** (`src/engine/`): pure TS, seeded RNG in state, JSON state. Revision 2 rules: 0 starting crystals (turn 1 = exactly 1), underdog +2 only if the enemy holds a site, Tunnel only while the enemy holds more sites, back-row-only summoning (front row only when the back row is full), Deploy → Action phases (a creature moves OR attacks; Charge may do both), simultaneous melee (defender strikes back even if defeated), full heal + Shield loss at the start of the owner's turn, numeric Shield X (Gnome Tinker, Madame Sprocket), Brewmaster +1 Health until next turn, Heavy Armor +3 Health, Commander damage = exact Attack (never resets), printed Health ≤ 6.
- **Content as data** (`src/content/*.json`, generated by `scripts/gen-content.mjs`), including `tutorial.json` and `game-config.json` (Deploy 30 s, Action 45 s, `starterDeckMix` 40/6/4). Starter decks: 40 creatures / 6 spells (incl. Fizzle) / 4 Crystal cards. Madame Sprocket is in `commanders.json` only (`playable: false`).
- **Tutorial match**: fixed setup, scripted do-nothing opponent, no timers, tip box (`aria-label="Tutorial tip"`), `state.tutorial.step` summon → move → capture → spend → fight → spell → commander → complete; "Skip Tutorial"; first-visit "Welcome to Oreheart!" dialog (localStorage `oreheart.tutorialSeen`).
- **UI**: landscape layout (left: crystals/decks, centre: 3D board with enemy hand on top and fanned hand below, right: phase/timer/Done/Health/Menu), "Please rotate your phone" overlay (portrait and < 900 px), menu Play/Tutorial/Rules/Settings, Settings with Graphics toggle, Rules page, damaged Health shown red with `data-damaged`, Shield icon, defender lunge on melee.
- **Test mode**: `?test=1[&seed=N]` exposes `window.oreheart` (`getState`, `legalActions`, `act`, `newMatch`, `startTutorial`).

## Notes / gaps
- Deck mix uses many copies of the Commons (no extra card names added).
- Champion's Crown also adds +3 current Health. Glowing Geode is Unique.
- `factory-data/oreheart-8` (spec and acceptance tests) was not modified, per instructions.
- Visuals are placeholders; no sound.
