# Oreheart — Phase 1a build notes

Vite + TypeScript (vanilla DOM) + Three.js. `npm run build` → `dist/`; `npm test` → Vitest (engine + AI tests).

## What was built
- **Rules engine** (`src/engine/`): pure TS, seeded RNG held in state, JSON-serializable state; `createMatch`, `legalActions`, `applyAction` (state + events). Covers sites/income/underdog, deploy (home rows, Tunnel, blocked-home rule), Crystal cards (+ Crystal Eater drawbacks), upgrades, movement (move 2, Flying), melee/ranged/strike back/type advantage/Guard/abilities, spells, Instants, counterspells and the Respond window, mulligan, deck-out, retreat and surrender.
- **Content as data** (`src/content/*.json`, generated by `scripts/gen-content.mjs`): all 41 starter cards, 3 Commanders, three 50-card starter decks, `game-config.json` with every tunable number.
- **AI** (`src/ai/ai.ts`): Easy (weighted random) and Normal (site contesting, Gatherer safety, Commander attacks, trades, spells, counterspells/Instants, mulligan). Uses only `legalActions`.
- **UI**: main menu, Commander/difficulty setup, mulligan dialog, match screen (Three.js scene with DOM overlay for stats/hit-testing, 2D fallback without WebGL), fanned hand (wheel/swipe), drag to summon/cast/move/attack, card view, upgrade menu, Respond dialog, match menu/surrender, retreat scene + Victory!/Defeat screen, How to Play, Graphics High/Low toggle (localStorage).
- **Test mode**: `?test=1[&seed=N]` exposes `window.oreheart` (`getState`, `legalActions`, `act`, `newMatch`); timers paused, AI runs synchronously inside `act()`/`newMatch()`.

## Decisions / known gaps
- Cast format extras: Tunnel Rush uses `{type:'cast', uid, target:{row,col}, to:{row,col}}` (`to` optional, auto-picked if omitted); Meteor Strike target = centre `{row,col}`; Heart of the Fallen `colors` = `{green,blue,purple}` counts (arrays of colour names also accepted).
- Crystal Eaters count as Gatherers for the +2 site bonus (role Gatherer). Glowing Geode is Unique (one per player).
- Ranged shots are blocked by sites/Strongholds/creatures in the middle space. Uncontrolled sites have `color: null`.
- Champion's Crown adds +3 max Health without healing (only Heavy Armor heals).
- Visuals are placeholder 3D figures; no sound; Commander emotes are simple bounces.
- Menu 'How to Play' uses role=link so getByRole('button',{name:'Play'}) is unambiguous.
