# Build notes
- Vanilla JS + Vite app; hash routing; data in localStorage `truck-inventory-v1`.
- All six pages implemented per SPEC (inventory CRUD with edit dialog, Quick Add parser + voice, tap-to-count Photo Count, Use Parts incl. bad parts, Restock list, Reports with filter + CSV downloads).
- Deviation: Inter is declared in the font stack but not loaded from Google Fonts (avoids network-failure console errors); system sans-serif fallback is used.
- Extra: editing a part to a name matching another part shows an error.
- Parts List page (#/parts-list): read-only, grouped by category, Out/Low/OK status, search, print stylesheet.
- Rebrand: "Chas Roberts Truck Inventory" title/header, blue #0073BB / red #E0144C on white theme.
- Logo: `brand/chas-roberts-logo.png` was NOT present in the repo, so a placeholder PNG (generated by `scripts/make-logo.mjs`) is at `public/chas-roberts-logo.png`. Drop the real logo over that file; no code change needed.
- Name understanding (`src/names.js`): name keys (sizes like "half inch" = `1/2"`, number words, synonyms, filler/plural rules), strict match for the Add/Edit forms, smart lookup (exact + partial token match, ambiguity error) for Quick Add / Use Parts / Photo Count, and size-aware search.
- Per-part "Other names" (add form, edit dialog, "Also called:" line, used in lookup and search).
- "Search by voice" button on Inventory and Parts List (shown only when speech recognition exists).
